# 🚀 CreatorFlow AI

### Create Smarter. Create Faster. Create with AI.

CreatorFlow AI is an AI-powered content creation platform designed to simplify the content creation process using intelligent AI technology.

Built for **GeNarrative Clash 2026 – GenAI & Prompt Engineering Hackathon**.

## 📌 Project Overview

CreatorFlow AI aims to make content creation smarter, faster, and more accessible through AI-powered content generation.

- **AI Content Generation:** Generate content using AI.
- **AI Integration:** Powered by Groq API.
- **User-Friendly Interface:** Simple and intuitive user experience.

## 💻 Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/abhibepari/creatorflow-ai.git
```

### 2. Navigate to the project folder

```bash
cd creatorflow-ai
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env` file in the project root directory and add:

```env
GROQ_API_KEY=your_groq_api_key
```

Replace `your_groq_api_key` with your actual Groq API key.

**Important:** Never share or upload your API key to GitHub.

### 5. Start the Backend

Open a terminal and run:

```bash
npm run server
```

### 6. Start the Frontend

Open another terminal in the project directory and run:

```bash
npm run dev
```

Open the local URL displayed in your terminal to access the application.
